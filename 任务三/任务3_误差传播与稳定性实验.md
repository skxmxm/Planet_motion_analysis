# 任务 3：误差传播与稳定性实验

## 概述

本任务通过对比 VSOP87 与 JPL DE430（模拟）计算得到的地球位置，进行误差传播与稳定性分析：
1. **时间演化实验**：观察误差随时间的增长曲线
2. **精度判定**：根据有效数字定义评估 VSOP87 的长期精度

---

## 1. 实验设计

### 1.1 模型对比

| 模型 | 类型 | 特点 |
|------|------|------|
| VSOP87 | 分析理论 | 三角级数展开，长期外推会累积截断误差 |
| DE430 (参考) | 数值历表 | 切比雪夫插值，精度高但时间范围有限 |

### 1.2 实验假设

由于实际 DE430 数据文件较大，本实验使用简化方法：
- **VSOP87**：使用任务2中的简化模型（基于三角级数）
- **参考值**：使用更精确的解析轨道模型模拟 DE430 的高精度结果

## 2. 实验 1：时间演化实验

### 2.1 实验方法

计算从 J2000.0 历元（JD = 2451545.0）开始，往前后各推 500 年（共 1000 年），步长 50 年：

```
时间范围: [-500, +500] 年
步长: 50 年
总计算点数: 21 个
```

### 2.2 误差定义

**绝对误差**：
- 黄经误差: ε_L = |L_VSOP87 - L_DE430| （弧度）
- 距离误差: ε_R = |R_VSOP87 - R_DE430| （AU）

**相对误差**：
- ε_R / R （距离相对误差）

### 2.3 实验结果

#### 误差随时间变化表

| 年份 | 黄经误差 (角秒) | 距离误差 (AU) | 距离相对误差 |
|------|----------------|--------------|-------------|
| -500 | 25475.04 | 0.000140 | 0.000142 |
| -250 | 12591.91 | 0.000140 | 0.000142 |
| 0 | 22.88 | 0.000140 | 0.000142 |
| +250 | 12369.45 | 0.000139 | 0.000141 |
| +500 | 24448.11 | 0.000137 | 0.000140 |

#### 误差增长趋势

**黄经误差**：
- 在 J2000.0 附近误差最小（约 23 角秒）
- 随时间远离 J2000.0，误差近似线性增长
- 500 年后误差达到约 24448 角秒（约 6.8°）

**距离误差**：
- 相对误差保持在约 1.4 × 10^-4 量级
- 增长较缓慢，说明距离计算相对稳定

#### 误差增长拟合

```
log(ε_L) ≈ 0.00316 × |t| + 3.10
log(ε_R) ≈ -0.000006 × |t| - 3.85
```

**结论**：
- 黄经误差随时间增长较快
- 距离误差增长较缓慢，数值稳定性较好

## 3. 实验 2：精度判定

### 3.1 有效数字定义

根据课程资料中的定义：

> 如果近似值 x* 的误差不超过某一位的半个单位，且该位到 x* 的第一位非零数字共有 n 位，则称 x* 有 n 位有效数字。

**有效数字与相对误差的关系**：

```
|x - x*| / |x| ≤ 1/(2×a1) × 10^(-(n-1))
```

其中 a1 是第一位有效数字。

**简化估计**：
```
n ≈ -log10(相对误差) + 1
```

### 3.2 1000 年后的精度分析

#### 距离 R 的分析

| 指标 | 数值 |
|------|------|
| 参考值 (DE430) | 0.9834932458 AU |
| VSOP87 计算值 | 0.9836266129 AU |
| 绝对误差 | 0.0001333671 AU |
| 相对误差 | 0.0001356055 |
| **有效数字位数** | **约 4.87 位** |

#### 黄经 L 的分析

| 指标 | 数值 |
|------|------|
| 参考值 (DE430) | 93.8954192145° |
| VSOP87 计算值 | 107.1742855137° |
| 绝对误差 | 13.2788662992° |
| 相对误差 | 0.1414218756 |
| **有效数字位数** | **约 1.85 位** |

### 3.3 不同年份的精度对比

| 年份 | 距离有效数字 | 黄经有效数字 |
|------|------------|------------|
| 100 | 4.85 | 2.86 |
| 500 | 4.85 | 2.16 |
| 1000 | 4.87 | 1.85 |
| 2000 | 4.91 | 1.54 |
| 5000 | 5.31 | 1.09 |

### 3.4 精度判定结论

**1000 年后**：
- 距离：保持约 4.87 位有效数字，精度尚可
- 黄经：仅保持约 1.85 位有效数字，**精度不足**

**综合判定**：VSOP87 在 1000 年后仅保持约 1-2 位有效数字，对于高精度天文计算已不适用。

## 4. 数值稳定性分析

### 4.1 误差来源分解

| 误差类型 | 表现 | 增长特性 |
|---------|------|---------|
| **模型误差** | VSOP87 简化假设 | 系统性，不随计算放大 |
| **截断误差** | 级数有限项截断 | 随时间累积，长期显著 |
| **舍入误差** | 浮点运算精度 | 本实验中影响较小 |

### 4.2 稳定性启示

1. **短期稳定性（< 100 年）**：
   - VSOP87 精度良好（3-5 位有效数字）
   - 适合大多数天文观测和计算

2. **中期稳定性（100-1000 年）**：
   - 精度逐渐下降
   - 截断误差成为主要误差来源

3. **长期稳定性（> 1000 年）**：
   - 精度严重不足
   - 建议使用数值历表（DE 系列）

## 6. 结论与建议

### 6.1 主要结论

1. **误差增长**：VSOP87 的黄经误差随时间近似线性增长，500 年后可达数度
2. **有效数字**：1000 年后 VSOP87 仅保持约 1-2 位有效数字
3. **适用范围**：VSOP87 适用于短期（< 100 年）天文计算

### 6.2 应用建议

| 应用场景 | 推荐模型 | 时间范围 |
|---------|---------|---------|
| 日常天文观测 | VSOP87 | < 100 年 |
| 航天任务规划 | DE430/DE440 | < 50 年 |
| 长期历史研究 | DE 系列 | 任意 |
| 考古天文学 | 数值积分 | 数千年 |

### 6.3 数值计算启示

1. **截断误差是累积性的**：有限级数展开的误差会随时间放大
2. **模型选择要考虑时间尺度**：不同时间尺度需要不同精度的模型
3. **有效数字是重要指标**：可用于定量评估计算结果的可靠性
